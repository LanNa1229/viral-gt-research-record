# Methods

**Reference and viral representations.** The published BGC-Prophet classifier was applied to isolated ordered MIBiG cores using the original published protein vectors from the training LMDB. Five augmented records for each of 2,502 biological reference BGCs were reconciled by accession after confirming identical core lists and labels. Embeddings were the 320-dimensional mean representation supplied to the classifier. The reference input for this analysis was the saved isolated CORE_ONLY array, rather than a contextual average across augmentations. For the viral windows, the 594 GT-anchor accessions were mapped to recorded GenBank CDS occurrences using the original exact sequence checks. Eligibility followed the observed translation and source checks. The 15- and 11-gene workflows used the actual ordered CDSs, including shorter boundary windows. The frozen CPU ESM2 checkpoint supplied the protein vectors and the frozen BGC-Prophet classifier supplied the 320-dimensional embeddings and seven scores.

**Candidate and representative selection.** The paired comparison used the original fixed 565 baseline loci. The union candidate rule was satisfied by at least one window from either size with Saccharide score ≥0.5 and at least the Other score, or Saccharide P@10 ≥0.5. P@10 used the ten nearest reference vectors by cosine similarity in 320 dimensions and counted every reference carrying Saccharide. Loci with usable 15-gene-workflow embeddings retained a single observed window with maximal mean within-locus cosine similarity. Lexicographic stable window identifiers broke ties within the documented tolerance of 1e-12. No 11-gene vector was substituted for an unavailable 15-gene representative. There were 556 observed representatives and 287 selected loci among them.

**Projection and clustering.** The original joint UMAP used 2,502 references and 556 viral representatives, with cosine distance, 2 components, 30 neighbors, min_dist 0.1, seed 42 and one job. The effective optimization epoch count as measured during execution is NOT RECORDED. One later provenance field reports 500 with attribution to the installed default, which is retained as retrospective documentation. Global Leiden used 2,502 references and 287 selected viral representatives in original 320-dimensional space. The weighted cosine graph used float64 L2 normalization, stable-ID tie-breaking, union symmetrization, k=20 and positive cosine edge weights. The RB configuration-model objective used resolution 1.0 and seed 42. The archive retains graph parameter and seed grids, duplicate-context, full-length and genome weighting sensitivities, and the viral-only HDBSCAN comparison.

**Reference composition and visualization.** Each marginal class fraction counts members carrying the original label over all reference BGCs in that community. Multilabel contributions may sum above 100%. The final panel uses unchanged joint UMAP coordinates, filled class-colored circles for single-label references, neutral open circles for 467 hybrids, and open triangles for 287 selected viral loci. Figure layout uses numeric Cartesian axes and a class legend. Community identifiers and composition are retained in the source data and caption.
