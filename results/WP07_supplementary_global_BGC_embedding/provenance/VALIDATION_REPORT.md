## Source integrity and release scope

All 303 files at the sealed source revision `72d124fc32d525f54304b715bc9aa8413eb2db85` matched the listed SHA-256 digests and byte lengths. The seal digest was `21c4ca56b35c5b2151b87918f164d470335ac3d32f15866657465efef47303ae`. All 13,528 members of the two bundled numeric archives matched their member digests. The public restorer successfully materialized the upstream tree and those bundled members using the public manifests.

The release resolved 36 files from the historic dependency manifest at revision `284d4f1655cf036c1890bdffcb4aa2dc93f6e41e`. They cover the global graph and assignments, exact embedding and identifier inputs, class summaries, recorded settings and global execution evidence. Two mixed-cohort result tables are published as global-row extracts, and the historical clustering Methods and evidence table are scoped to this figure. Workstation identifiers and personal contacts were screened from published provenance copies. Figures and retained numerical outputs preserve their original bytes.

Sixty-one distinct public Git paths were reused at `2776f9828b905f1573d104a809d1e3059aae0629` after exact SHA-256 comparison. The [source map](RELEASE_SOURCE_MAP.tsv), [public dependency manifest](PUBLIC_DEPENDENCIES.tsv) and [omission ledger](SCREENED_OMISSIONS.tsv) record the file-level decisions and digests. The [public release checksums](ARCHIVE_SHA256.tsv) cover all package files other than the checksum manifest itself.

## Figure redraw

The archived plotting script used the saved coordinates, memberships, marginal counts and palette to render PNG, PDF and SVG in a new directory. The redrawn 4,322 × 2,598 PNG matched the archived PNG pixel for pixel. The Arial regular font used in the redraw had SHA-256 `edfbd22a3d088fc2f5d7c79b8c9c732df6dc878a60f0a80be0f92a3c7a634404`. The original manuscript exports are included. Exact binary equality of fresh vector exports was outside this validation.

## Global Leiden reconstruction

All 556 representative vectors matched their original embedding rows. The 2,502 public reference vectors and 287 selected representative vectors reproduced the 2,789 × 320 global input matrix in historical row order. Rebuilding the k=20 cosine graph gave the identical set of 39,384 undirected edges. The maximum absolute weight difference was 4.44 × 10⁻¹⁶. The saved partition matched all 2,789 sample identifiers, all ten communities, all 70 reference class counts and the plotted coordinates. Independent arithmetic reproduced the saved weighted RB objective (62192.003468486844) and weighted modularity (0.8167859718014231).

The release includes the captured Leiden engine, exact baseline configuration and a command for an independent researcher to replay the optimizer. Publication verification reconstructed the graph and checked the recorded partition and objective. No optimizer, UMAP fit or embedding model was rerun.

## External inputs and historical limitations

An upstream replay needs the published protein-vector LMDB, model checkpoints and versioned GenBank records listed in the [external dependency manifest](EXTERNAL_DEPENDENCIES.tsv). The 15.1 GB LMDB digest survives as historical evidence. Exact downloaded GenBank bytes can vary as source annotations are updated. The frozen arrays and public tables suffice for the figure redraw and graph reconstruction. The effective epochs of the initial UMAP fit and exact fit-time script bytes were unrecorded, and some early run transcripts could not be recovered.
