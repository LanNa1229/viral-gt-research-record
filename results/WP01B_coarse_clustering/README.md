# WP01B — Foldseek coarse clustering

## Purpose

WP01B establishes the coarse structural-clustering baseline used to define
multi-member clusters and singleton proteins in Section 1 of the viral
glycosyltransferase study.

The record links the raw Foldseek assignments, internal-ID mapping, canonical
biological membership, original analysis code, and independent reconstruction
validation.

## Validated reconstruction

The following transformation was validated across all 1727 proteins:

```text
raw/cluster_cluster.tsv
+ raw/protein_db.source
→ canonical/cluster_membership.tsv
```

The reconstructed output and canonical membership were identical byte for
byte. No missing, duplicated, multiply assigned, or mismatched protein
assignments were detected.
