This record documents the provenance and integrity of the structural input

The archive contains the PDB input structures used for the Foldseek workflow.
This record is provided to preserve the relationship between the original

3. RELATIONSHIP TO COMPUTATIONAL ANALYSIS

These 1727 PDB structures were used as the structural input set for the
Foldseek clustering workflow.

The workflow included:

  foldseek createdb

  foldseek cluster
    --min-seq-id 0.0
    -c 0.05
    --cov-mode 0
    --threads 64

  foldseek align
    -a
    --threads 64

  foldseek convertalis

The workflow generated a Foldseek structural database, cluster assignments,
representative-versus-member alignments, and an m8-format alignment file.

This archive documents the original PDB input set. Foldseek-derived outputs
are not included in this archive unless separately identified and transferred.
