# Manuscript Claim Records

Create one Markdown file per major claim:

```text
manuscript_claims/CLM-VGT-001-cluster8-family.md
```

Each claim file should contain:

- exact current claim wording;
- scope and strength of claim;
- direct observations;
- analytical evidence;
- biological interpretation;
- alternative interpretations;
- limitations;
- linked notebooks;
- linked commits;
- linked figures and tables;
- linked contribution ledger entries;
- status and review history.

Do not silently strengthen claim language. Record major wording changes in Git and update the claim-evidence matrix.
