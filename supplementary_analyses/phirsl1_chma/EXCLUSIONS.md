# Scope and exclusions
No source files were deleted.
- Publisher PDFs, supplementary PDF/XLSX/CSV files, source-table screenshots and article XML: withheld from this public package to avoid redistributing publisher-controlled material; DOI/accession/provider references retained.
- Downloaded supplementary ZIP archives and compressed AlphaFold DB duplicates: omitted as redundant; the actual decompressed model inputs are included.
- Raw multichain experimental mmCIF downloads and tagged entity FASTAs: omitted as redundant; the processed monomers actually compared are included.
- Earlier five-reference exploratory outputs, superseded figure versions, temporary previews, software environments, regenerable Foldseek databases and scratch files: outside the final publication archive.
- Duplicate ChmA monomers from the AF3 update directory are stored once under inputs/chma_monomers.
- No file excluded for exceeding GitHub's ordinary 100 MiB file limit. File sizes checked before publication.
