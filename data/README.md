# Data Directory

Large research data are not stored directly in this Git repository.

This directory is a documentation anchor. Raw, intermediate, and large final datasets should be placed on UGA-managed or UGA-approved storage. Record each dataset in `metadata/manifests/` with a dataset ID, storage location, source, version, checksums, access classification, and related notebooks.

Do not place credentials, restricted data, controlled data, or unpublished large datasets in an unapproved remote repository.
