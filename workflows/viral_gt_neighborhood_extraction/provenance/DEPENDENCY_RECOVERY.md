# Historical dependency recovery and portability changes

All 820 files referenced by the original 11-gene `verify_prior` gate were found locally and matched their stored hashes:676 baseline,97 interpretation and47 retrieval-rescue records. Exact path/size/hash evidence is retained in the local review file `recovered_11gene_dependencies.tsv`. These records are historical artifacts, not reconstructed replacements. Their broad inference/plot/control payloads are not needed for CDS selection and are not added to this Step1 release.

Recovered original computational ingredients include the full frozen15 implementation snapshot, exact11 experiment.py/common.py, source annotations, original aliases and hash evidence, the old Python3.12.11/Biopython1.85 environment, and all archived 757-row size-pair relationships. The byte-for-byte historical source manifest records identities separately from new portable code. Original script locations remain in provenance; these paths are metadata, not portable execution defaults.

New adaptation: `portable/step1.py` executes the hash-pinned extract module and isolates the unchanged `shortened` and structural grouping function ASTs. It does not import the legacy common/inference/analysis modules wholesale or execute their main functions. This removes only their top-level path/import/guard coupling from the new adapter; original scripts are untouched. Per-input checksum verification, fixed historical core hashes, safe output creation and exact fixture regressions replace broad unrelated preservation gates in the new workflow.

Unresolved historical limitations: no exact original shell argv transcript or full original dependency lock was located; original code was uncommitted; universal original BFVD sequence-version identity is not established. The original source mapping was bounded by explicit crosslinks. Subsequent full-cohort validation reproduced all scientific extraction results; no model result was regenerated. Preserve these distinctions in publication claims.
